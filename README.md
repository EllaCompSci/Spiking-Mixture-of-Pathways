# Spiking-Mixture-of-Pathways
Masters of research project at the university of Sussex with supervision for Jamie Knight. The goal of this research project is implement Heterogeneous Mixture of expert (HMoE) along with the inductive biases stated in Cook et al. (2026, DOI: 10.52202/085713-2800) to produce brain like processing pathways. This implementation uses GeNN library along with MlGeNN as EventProp implementation will be used for training said model.
